How It Works
Understanding the crawler

The crawler performs a Breadth-First Search (BFS) starting from your origin URL. Depth k represents the number of hops from the origin page.

Backpressure mechanisms ensure controlled load:

  • Token bucket rate limiter (10 req/s)
  • Bounded queue (max 10,000 URLs)
  • Thread pool (5 concurrent workers)
